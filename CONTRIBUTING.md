# Contributing

Bug reports, domain packs, tests, and focused pull requests are welcome.

1. Create a virtual environment and run `pip install -e .`.
2. Run `python -m unittest discover -s tests -v`.
3. Keep deterministic behavior as the default and mock model calls in tests.
4. Do not include confidential expert answers, credentials, or customer data.

By contributing, you agree that your contribution is licensed under Apache-2.0.
